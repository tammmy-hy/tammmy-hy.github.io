Overview

This project was developed as a five-week final project for IAT238 Foundations for Designing Interactions. The goal was to design a microsite for Dutch Design Week while applying the visual principles of Wim Crouwel.

Initial 3 Microsite Concepts

Feedback

Professor’s feedback highlighted the strengths of both Concept 1 and Concept 3. Concept 1 communicated information clearly through stronger typography and hierarchy, while Concept 3 offered a more distinctive visual identity, engaging landing page, and greater interaction potential. He suggested combining the clarity and readability of Concept 1 with the visual experimentation and interactive qualities of Concept 3. This feedback ultimately guided the final direction of the microsite.

Challenge & Solution

One key challenge was implementing a scroll-based text reveal interaction inspired by advanced web animations. Initially, I found that this effect is typically achieved using coding-based tools such as GSAP, which are not directly supported in Figma.

To address this limitation, I explored alternative techniques within Figma's prototyping system. By using layered elements, opacity adjustments, and Smart Animate transitions, I was able to recreate a simplified version of the interaction.

This process demonstrated the importance of adapting design ideas to technical constraints and strengthened my ability to translate visual systems from static design into interactive experiences.

Reflection

This project taught me the value of iteration and feedback in the design process. By combining concepts, refining interactions, and solving technical constraints within Figma, I learned how small design decisions can significantly improve the user experience. It strengthened my ability to balance visual experimentation with usability while creating a more engaging and intuitive microsite.
